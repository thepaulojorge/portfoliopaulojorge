# 💼 Portfólio — Paulo Jorge

Portfólio pessoal desenvolvido do zero com HTML, CSS e JavaScript puro — sem frameworks ou bibliotecas externas.

🔗 **[Acessar o portfólio](https://thepaulojorge.github.io/portfoliopaulojorge/)**

---

## ✨ Funcionalidades

- 🌙 **Modo escuro/claro** com preferência salva no localStorage
- 🌐 **Multilíngue** — Português, Inglês, Francês e Japonês
- ⌨️ **Efeito de digitação** no nome do hero
- 🖼️ **Modal de projetos** com carrossel de screenshots
- 📬 **Formulário de contato** funcional via Formspree
- 🎞️ **Animações de entrada** suaves com IntersectionObserver
- 📱 **Totalmente responsivo** — mobile, tablet e desktop
- ♿ **Acessível** — aria-labels, focus-visible e prefers-reduced-motion
- 🔍 **SEO** — meta tags, Open Graph, Twitter Card e Schema.org
- 🎨 **Formas geométricas animadas** no hero, projetos e contato

## 💡 Destaques técnicos

**HTML semântico** — uso correto de `<main>`, `<article>`, `<section>`, roles ARIA e atributos de acessibilidade.

**CSS moderno** — variáveis CSS para design tokens, dark mode via classe no `body`, `clamp()` para tipografia fluida, `IntersectionObserver` para animações de entrada, `prefers-reduced-motion` para acessibilidade.

**JavaScript puro** — sem dependências externas. i18n manual com objeto de traduções, carrossel de imagens, formulário assíncrono com Fetch API e persistência com localStorage.

**SEO completo** — meta description, Open Graph, Twitter Card, Schema.org (Person) e canonical URL.
